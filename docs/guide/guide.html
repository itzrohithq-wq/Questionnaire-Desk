Start here

Questionnaire desk is a demo of a simple idea: software suggests an answer, and you decide. Nothing goes into the Excel file until you approve it.

1

Open the link

Use any current web browser on a computer or phone. There is nothing to install and no account to make.

Open Questionnaire desk

https://questionnaire-desk.vercel.app/

2

Review the answers

A sample questionnaire with 21 questions loads for you. The software suggests an answer where a fictional company policy supports one.

3

Download the result

Only answers you approved are written into a copy of the Excel file. Everything else stays blank.

Good to know before you start

All names, policies and answers are fictional. The matching is simple keyword matching, not artificial intelligence, so many questions will have no suggestion. That is on purpose. Nothing you do is sent anywhere or saved on a server. Please do not use real company files.

Your first review in 4 steps

Where
The live demo.
What it is for
Approve two answers and download an Excel file that contains only those two. About four minutes, no cost.

Left: the evidence for Question 3. Right: the Approve button you will press.

What you should end up with

The button at the top right reads “Export Excel (2 approved)”. The file you download has an answer next to exactly those two questions, and the rest is blank.

  1. 1

    Press Start the interactive demo, then click Question 3 in the list.

  2. 2

    Read the highlighted sentence on the right. It says customer data at rest is encrypted. Press Approve.

  3. 3

    Click Question 9 (“Do you test restores from backups?”), read its sentence, press Approve.

  4. 4

    Press Export Excel (2 approved) at the top right and open the file.

Common mistake: approving without reading the sentence. The software can be wrong; you are the check.

When the software drafts nothing

Where
Middle column, above the answer box.
What it is for
Explains why a question has no suggestion, so a gap is never filled with a guess.

Question 2: the closest policy sentence is negative or conditional, so nothing is drafted. Question 1 looks the same, but its note says no supporting evidence was found.

What you should see

The answer box says “No suggested answer”, and the Approve button is greyed out.

  1. 1

    Click Question 1 or Question 2.

  2. 2

    Read the note. It tells you whether the software found a doubtful sentence or nothing at all.

  3. 3

    If a policy does cover the question, write the answer yourself (see “Write your own answer”).

On purpose: the demo prefers a blank to a guess.

Reject, or ask for more evidence

Where
Right column, “Reviewer actions”.
What it is for
Keeps weak or unsupported answers out of the Excel file.

A rejected answer. Its cell stays blank in the Excel file.

What you should see

The label says “Rejected, will not export” or “More evidence needed”.

  1. 1

    Open a question whose evidence does not support the answer.

  2. 2

    Press Reject to throw the suggestion away, or Needs more evidence if you need a better policy first.

  3. 3

    You can still change your mind later and press Approve.

Rejected and held answers are never downloaded.

Write your own answer

Where
Right column: Reviewer actions → “Edit answer”.
What it is for
Lets you answer a question the software missed, or fix a suggestion, and link it to a policy sentence.

The edit form. The Yes / No / N/A choice matches the dropdown in the Excel file.

  1. 1

    Press Edit answer. Choose Yes, No or N/A. A comment is optional.

  2. 2

    Under “Cited evidence” pick the policy sentence that supports your answer.

  3. 3

    Press Save edit, then press Approve. Saving does not approve it.

What you should see

After you press “Save edit” the label reads “Edited, needs approval”, and the box is dashed again.

Every edit cancels an earlier approval. If you cite nothing, the Excel file says “Source: none cited; answer entered by the reviewer.”

Start over

Where
Left sidebar, circular-arrow icon “Reset demo”.
What it is for
Clears every approval, rejection, edit and hold so you can run the demo again.

The sidebar: Guided tour, Limits and Reset demo. A label shows when you point at an icon.

What you should see

A short message “Demo reset. All review choices were cleared.”, and Export Excel greys out again.

  1. 1

    Press Reset demo.

  2. 2

    Check that the count says 0 approved.

  3. 3

    Your choices stay if you reload the page, but they are kept only in this browser tab, so closing the tab also clears them.

Nothing is saved on a server and nothing is shared between tabs or devices.

For developers: run it yourself

Where
A terminal in the secq-demo folder.
What it is for
Run the demo on your own computer, and check that it still behaves as described. These are commands, not screens.
npm install
npm run build
npm run serve          # opens http://localhost:3100

npm run test:unit      # matcher, review rules, export check
npm run test:e2e       # browser tests, desktop and phone
npm run data           # rebuild data from the Python prototype

The code is at github.com/itzrohithq-wq/Questionnaire-Desk. Pushing to its main branch redeploys the live site on Vercel.

What you should see

The terminal prints http://localhost:3100. The unit tests list 36 passing; the browser tests list 25 passing and 5 skipped on purpose.

  1. 1

    Run npm install once, then npm run build.

  2. 2

    Run npm run serve and open http://localhost:3100.

  3. 3

    Run the tests whenever you change something.

Local upload switch: set the build variable NEXT_PUBLIC_ALLOW_UPLOAD=1 to show a file chooser for your own fictional .xlsx files. The live site never has it. Never load real customer files.

Checklist and limits

Check these before you show the demo to someone else.

Before you show it

  • https://questionnaire-desk.vercel.app/ opens and shows the welcome screen.
  • You can approve, reject, edit and restore a question.
  • A download with 2 approvals has exactly 2 answers.
  • You told people it is keyword matching, not AI.
  • No real company files are used.

What this guide covers

  • Every control in the live demo, in the order you meet it.
  • Starting, reviewing, downloading, the tour, the limits, phones and reset.
  • Developer commands for running and testing it.

Not part of the demo

  • Accounts, billing and real-file upload.
  • An expert human review. That is a separate service idea, not this software.

Limits and what was checked

  • In the sample, 5 of 21 questions get a suggestion.
  • The Excel file was checked on the sample only; images, charts and macros are not supported.
  • Tested in Chromium on a computer and in a phone-sized window, not on real phones or other browsers.
  • Pictures in this guide are real screens of the live site, shown at 100% size.
  • This is not a Tango export.
